# Casa Solea Garda

Public-facing hospitality website prototype for Casa Solea in Pacengo di Lazise, Lake Garda.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated static site is written to `dist/`.

## Deploy

This project is configured as a Vite + React + TypeScript site and can be deployed on Vercel, Cloudflare Pages, Netlify, or another static host.

- Build command: `npm run build`
- Output directory: `dist`
- Node.js: current LTS

## Important

The current site is a prototype. Booking/channel synchronization, checkout/payment, host administration, legal details, contact information, and some imagery/content are placeholders or mock UI and must not be treated as live services.

The host/admin portal is intentionally disabled in the public static preview. Implement server-side authentication before enabling it.
